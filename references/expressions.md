# 18类夸张表情

默认4/5：真实人物明显地做出反应，缩略图一眼能识别。1为轻微，2为略夸张，3为明显，4为本技能默认强反应，5为用户明确要求时的极强反应。通过眉眼、嘴型与头部动作增强表情，保持骨相、年龄、鼻形、眼型和身份；张大嘴是允许的表情，放大眼球或改变下颌骨是身份变形。

每张选择一个主情绪，写具体面部动作，不只说“夸张”。头部和手势配合情绪，同时留出读字空间；手不挡主要五官。以下为用户创作库，不是博主最新50条的统计结果。

| 编号与情绪 | 眉眼和嘴型 | 头部和手势 | 适用主题 |
|---|---|---|---|
| E01 震惊 | 双眉明显高抬，眼睑大幅打开，嘴呈清楚的惊讶O形 | 头稍后仰，张开掌心 | 反常识、意外结果 |
| E02 惊喜 | 双眉上扬，眼睛明亮张开，张嘴笑并露上齿 | 上身向前，手掌打开向标题示意 | 新方法、发现、成果 |
| E03 恍然大悟 | 双眉突然抬高，视线向标题，嘴明显张开成笑 | 头抬起，一根食指上举 | 关键原因、卡点解释 |
| E04 强烈好奇 | 眉明显抬高，睁眼看侧上方，嘴微张但眼部反应强 | 头明显侧倾，手托下巴 | 为什么、机制解释 |
| E05 强烈质疑 | 一侧眉高抬、另一侧压低，眼略眯，嘴唇明显偏向一边 | 头明显倾斜，手托下巴 | “真有这么简单？”、避坑 |
| E06 懵了 | 眉内侧明显聚起，眼睁大，嘴张开呈困惑形 | 头偏一边，两手可摊开 | 看不懂、复杂问题 |
| E07 无奈吐槽 | 眉内侧高抬，眼睑明显收窄，嘴角下压或侧撇 | 侧头、摊手、略耸肩 | 反复失败、常见错误 |
| E08 自嘲苦笑 | 眉明显不对称，眼角收起，一边嘴角明显上提 | 耸肩、头偏、摊掌 | 个人踩坑、糗事 |
| E09 后悔 | 眉头明显紧收，眼略眯，嘴张开像说“哎” | 手拍额头侧面，保留双眼 | “我早该知道”、返工 |
| E10 急切提醒 | 眉头收拢但眉内侧抬起，眼睁大直视镜头，嘴明显张开说重点 | 身体前倾，食指在肩旁举起 | “先别急”、操作关键点 |
| E11 强烈劝停 | 眉上扬、眼睁大，嘴明显张开像说“等等” | 头前倾，掌心向外暂停 | 先别买、先别做 |
| E12 担忧犹豫 | 眉内侧明显上抬聚起，眼神集中，嘴角明显下压 | 头微后缩，手托下巴 | 成本、风险、选择 |
| E13 兴奋分享 | 眉上扬、眼明亮，张嘴露齿笑 | 上身前倾，手指向文字旁 | 方法、步骤、经验 |
| E14 得意窍门 | 一侧眉高抬，眼角收起，嘴角明显上翘 | 偏头、拇指上举 | 简单技巧、隐藏用法 |
| E15 松一口气 | 眉舒展，眼角收起，嘴张开大笑但不仰头狂笑 | 放松肩部，摊掌 | “终于解决了”、安慰 |
| E16 热情跟做 | 眉抬高、眼直视，嘴张开友好笑 | 前倾、招手或向标题示意 | 跟做、实操教程 |
| E17 对比不信 | 单眉高抬，眼明确看对比项，嘴唇明显侧撇 | 头转向文字，手掌托向一侧 | 前后对比、两种方案 |
| E18 心疼成本 | 眉内侧高抬、眼略眯，嘴明显下撇或张开感叹 | 手碰胸口或摊开，头后缩 | 钱、时间、损失 |

路由：发现E01/E02/E03；方法E13/E16；问题E04/E06；质疑E05/E17；踩坑E07/E08/E09；提醒E10/E11；风险E12；技巧E14；解决E15；成本E18。用户指定情绪优先。两画幅保持同一种情绪和手势含义，允许为布局轻调头部方向。

提示词必须明确“EXAGGERATED, not slightly exaggerated, expression intensity 4/5”，再描述选定动作，加入“preserve identity and natural anatomical facial movement”。避免把“自然”写成要求表情微弱。成图若仍是日常微笑，应增强具体动作后修正。
